# Python College Programs

## Programs Included

### 1. Number System Conversion

This program performs the following conversions:

* Decimal to Binary
* Decimal to Octal
* Decimal to Hexadecimal
* Binary to Decimal
* Octal to Decimal
* Hexadecimal to Decimal

### 2. Electricity Bill Management System

This program allows the user to:

* View Electricity Bill
* Calculate Bill Based on Unit Consumption
* Check Payment Status
* View Consumer Details
